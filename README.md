# UAA 书名完整显示与卡片自适应

面向 ScriptCat、Tampermonkey 和 Violentmonkey 的轻量用户脚本，用于完整显示 UAA 小说书名，并让书籍卡片随标题长度自动增高。

## 功能

- 小说列表页：解除单行省略号，长书名自动换行。
- 首页与频道海报：解除一行或两行限制，完整显示长书名。
- 卡片自适应：标题增加行数时，卡片高度随内容增长，不覆盖作者、评分等信息。
- 原创首发标题：徽标与书名首行并排，长书名的后续行从徽标左侧基准对齐。
- 卡片视觉比例：封面保持 2:3 竖版比例，标题、简介和目录采用与参考卡片一致的紧凑行距。
- 列表卡片布局：封面列按参考图收窄，目录标签保持单行，章节名称最多显示两行。
- 列表卡片紧凑模式：书名与信息行距进一步压缩，最新章节单行省略显示。
- 书籍说明最多显示三行并保留省略号，避免说明与后续目录、标签重叠。
- 收藏页仅在手机端使用三列紧凑布局（缩小封面与文字），PC 端保持站点原始布局；详情页章节文字采用更小字号以显示更多内容。
- 收藏卡片作者与分类标签使用相同的小字号；手机端隐藏观看量、收藏量、肉量等统计的图标、文字与数字。
- 详情页“最新：”行与列表卡片一致：章节名小字号、粗体、灰白色，完整换行不再两行截断。
- 手机端详情页：缩小封面列并去掉行尾箭头，加宽“最新：”行，让时间与章节名同排显示。
- 详情页“最新：”行间距与列表卡片一致：“最新：”、章节名与时间之间无额外间距，时间紧贴章节名右侧。
- 收藏页分类：按观看历史「续读」章节与最新章节对比，提供“全部 / 阅读中 / 追更 / 已读完”Tab。
- 收藏页跨页统计：自动拉取全部分页，Tab 计数覆盖全部收藏，点击分类显示该类全部书籍。
- 本地阅读进度：章节页记录每本小说读到第几章，长期保存，弥补服务器 90 天历史限制。
- 设置面板：脚本菜单「UAA 设置」可自定义开关分类 Tab、跨页统计、本地进度、收藏页紧凑布局与详情页「最新：」样式。
- 详情页信息排版：使用紧凑的无衬线字体层级，书名、作者、元信息和简介适配手机宽度；“最新：”保持单行，最新章节与章节目录名称最长显示两行并左对齐，不再撑出横向滚动条。
- 动态内容兼容：只注入 CSS，分页、筛选及异步加载的新卡片无需额外扫描即可生效。
- 脚本图标：内嵌 UAA 官方图标，不依赖站点网络请求，便于手机端识别。

## 生效范围

- `vip261112.com` 及其子域名。
- `uaa.com`、`uaa001.com`、`uaa002.com` 等以 `uaa` 开头的 `.com` 镜像及其子域名。

## 安装

手机浏览器安装 ScriptCat、Tampermonkey 或 Violentmonkey 后，打开以下地址即可安装：

<https://raw.githubusercontent.com/lingyuncrystal/uaa-full-book-titles/main/uaa-full-book-titles.user.js>

脚本内置固定的下载与更新地址，后续可直接通过脚本管理器检查更新。
